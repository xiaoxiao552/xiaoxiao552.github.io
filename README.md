# 汤银晓 · 在线简历

数据分析师求职用在线简历（静态单页网站，自包含、无外部依赖）。

## 内容
- 求职意向：数据分析师
- 教育背景：大连财经学院 · 管理学院 · 大数据管理与应用（2023 级本科，预计 2027 年毕业）
- 校园任职 / 荣誉奖励 / 竞赛奖项 / 技能证书 / 自我评价

## 特性
- 单文件 `index.html`，内联 CSS，零外部依赖，离线可用
- 桌面 / 平板 / 手机响应式
- 深色 / 浅色主题切换
- A4 打印排版：浏览器「打印 → 另存为 PDF」即得标准简历 PDF

## 本地预览
直接用浏览器打开 `index.html` 即可。

## 部署到 Gitee Pages
1. 在 Gitee 新建仓库（勾选「使用 Readme 初始化仓库」，仓库可见性设为**公开**）
2. 将本目录内容推送到 `master` / `main` 分支
3. 进入仓库 → 顶部导航「服务」→「Gitee Pages」→ 选择分支与部署目录 → 点击「启动」
   （首次需账号已完成实名认证，启动后可能需等待审核）

访问地址：
- 仓库名为 `resume` → `https://<用户名>.gitee.io/resume/`
- 仓库名为 `<用户名>.gitee.io` → `https://<用户名>.gitee.io/`
